# CareerLens

CareerLens is a full-stack web application that helps users compare their resume skills with the skills required for a target job role.

## Features

- User registration and login
- JWT-based authentication
- Resume PDF upload
- Resume skill extraction
- Job-role based skill matching
- Match percentage calculation
- Matched and missing skill identification
- Personalized learning recommendations
- Analysis history
- React-based dashboard

## How It Works

1. User creates an account or logs in.
2. User uploads a resume.
3. CareerLens extracts skills from the resume.
4. User enters a target job role.
5. CareerLens identifies relevant skills for the role.
6. The system compares the resume skills with the required skills.
7. CareerLens calculates a match percentage.
8. Missing skills and recommendations are displayed.
9. Analysis results are stored for later viewing.
